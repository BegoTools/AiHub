# 🚀 AI Tools Hub - منصة أدوات الذكاء الاصطناعي الأقوى باللغة العربية

منصة ويب متكاملة، حديثة ومتجاوبة، تقدم **38 أداة ذكية** مخصصة لمجالات الدراسة، الكتابة، التسويق، البيزنس، الصحة والجيم، التقنية وصناعة الأوامر. المنصة مصممة بـ واجهة مستخدم متمثلة باللغة العربية مع لمسة مصرية ظريفة ملائمة وسهلة الفهم للجميع.

---

## 🎨 مميزات المنصة الرئيسية

1. **38 أداة ذكية متخصصة**: تغطي كافة الاحتياجات اليومية للدارسين والمهنيين والمسوقين وصناع المحتوى.
2. **اتصال آمن ومستور (Secure AI Proxy)**: جميع الطلبات تتم عبر خادم خلفي آمن (`Express`) لتشفير وحفظ مفاتيح الـ API بعيداً عن أعين المتصفحين والواجهة الأمامية.
3. **مزود ذكاء مزدوج**: إمكانية الاختيار السلس بين **Google Gemini 3.5 Flash** (الأساسي والمجاني) أو **OpenRouter API** الاحتياطي.
4. **تخزين محلي خفيف (Zero Server Databases)**: لا يتطلب التسجيل أو إنشاء حسابات، يتم حفظ السجل ومفضلات الأدوات والإعدادات محلياً في المتصفح بكل خصوصية.
5. **مظهر مائي وداكن (Light & Dark Modes)**: توافق بصري ممتاز ومريح للعين مع استخدام خط Cairo الأنيق لجمال الحروف والتحكم التام.
6. **بحث كلي مرن (Global Search)**: ابحث عن أي أداة بمجرد كتابة اسمها ليصلك الترشيح الذكي فوراً.
7. **إمكانية الملء بأمثلة توضيحية**: كل أداة تحتوي على زر "مثال توضيحي" لتعبئة الحقول أوتوماتيكياً وتجربة التوليف السريع.
8. **تصدير كملف نصي وسرعة نسخ**: انسخ النتيجة بضغطة زر أو حملها كملف نصي `TXT` لحقظ عملك.

---

## 📂 الهيكل والملفات في المشروع

- `/server.ts` : خادم الـ Express الخلفي والمؤمن لوصلات الذكاء وتشفير واستقبال مفاتيحك.
- `/src/App.tsx` : واجهة التطبيق التفاعلية الممتدة والأقسام وحالة الصفحات الدقيقة.
- `/src/components/` : المكونات المتبعة من سايدبار تليفوني، نماذج تعبئة، ومعالج مخرجات.
- `/src/data/categories.ts` : ترويسات الأقسام والهايلات ودرجات الألوان لكل قسم.
- `/src/data/tools.ts` : مصفوفة الـ 38 أداة المتكاملة بكافة البرومبتات التعليمية والروتين والرياضة والبرمجة.
- `/tsconfig.json` & `/vite.config.ts` : إعدادات المترجم والسرعة وبناء المستندات.

## 💻 خريطة التثبيت والتشغيل المحلي

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### خطوات التشغيل

1. **تثبيت الحزم المطلوبة**:
   ```bash
   npm install
   ```

2. **تهيئة ملف المفاتيح السرية**:
   قم بإنشاء ملف باسم `.env` بجانب ملف `package.json` واكتب مفتاحك الخاص:
   ```env
   GEMINI_API_KEY="ضع_هنا_مفتاح_جيميني"
   OPENROUTER_API_KEY="ضع_هنا_مفتاح_أوبن_روتر"
   ```

3. **تشغيل الخادم المحلي للتطوير**:
   ```bash
   npm run dev
   ```
   *سيقوم الخادم تلقائياً بالعمل وتشفير الوصلات على الرابط المباشر: http://localhost:3000*

4. **بناء المشروع للإنتاج (Production Build)**:
   ```bash
   npm run build
   ```
   *سيتم بناء الملفات المصغرة مجمعة في مجلد `dist/` مع كود الخادم المدمج بداخل `dist/server.cjs` لموثوقية وسرعة تشغيل قصوى.*

5. **بدء تشغيل نسخة الإنتاج المجمعة**:
   ```bash
   npm run start
   ```

## 📱 إرشادات تحويل التطبيق إلى تطبيق أندرويد (Android App)

إذا كنت ترغب بتحويل موقع **AI Tools Hub** التجريبي إلى تطبيق أندرويد متكامل ومثبت على هواتف المستخدمين، توجد عدة طرق موثوقة ومجانية ممتازة:

### الخيار الأول: تحويله باستخدام Capacitor (موصى به لبيئات الويب والـ React)
أداة Capacitor الرسمية من شركة Ionic تعمل على حزم موقع الـ React + Vite الخاص بك وبناء حزمة أندرويد نيتيف كاملة بسرعة مذهلة:

1. **تثبيت Capacitor بالمشروع**:
   ```bash
   npm install @capacitor/core @capacitor/cli
   ```
2. **تهيئة Capacitor**:
   ```bash
   npx cap init "AI Tools Hub" "com.aitoolshub.app" --web-dir=dist
   ```
3. **تثبيت منصة الأندرويد لـ Capacitor**:
   ```bash
   npm install @capacitor/android
   npx cap add android
   ```
4. **بناء موقع الويب أولاً ثم نقله لمجلد الأندرويد**:
   ```bash
   npm run build
   npx cap sync
   ```
5. **فتح المشروع واستخراج حزمة الـ APK**:
   ```bash
   npx cap open android
   ```
   *سيفتح لك بيئة Android Studio بضغطة زر واحدة، كل ما عليك هو عمل Build لحزمة الـ APK الموقعة وتثبيتها على تلييفونك فوراً!*

### الخيار الثاني: تحويله باستخدام Progressive Web App (PWA)
قمنا بإعداد المشروع ليدعم المتجاوبة الكامل، يمكنك تفعيل الـ PWA ليقوم الزائر بإضافة الموقع مباشرة من متصفحه لشاشة الهاتف بهيئة تطبيق أندرويد مستقل يعمل بدون شريط المتصفح المزعج وبأداء سريع جداً.
