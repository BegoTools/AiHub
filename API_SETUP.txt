========================================================================
                      AI Tools Hub - دليل إعداد المفاتيح والتشغيل
========================================================================

أهلاً بك في منصة "AI Tools Hub" للأدوات الذكية باللغة العربية.
هذا الملف يوضح لك بالتفصيل والخطوات البسيطة كيفية تهيئة مفاتيح البرمجة (API Keys) وتشغيل المنصة بنجاح كامل على خادمك المحلي أو الاستضافة.

------------------------------------------------------------------------
1. أين تضع مفتاح Google Gemini API Key؟
------------------------------------------------------------------------
لديك طريقتان مريحتان لإعداد وتشغيل مفتاح Gemini:

خيار أ: عبر رمز البيئة السري والمحمي (موصى به للأمان والإنتاج)
- نقوم بقراءة رمز Gemini مباشرة من بيئة الخادم (Server Environment).
- قم بإنشاء ملف باسم `.env` في المجلد الرئيسي للمشروع (بجوار ملف package.json).
- أضف السطر التالي للملف واستبدل الجزء الأخير بمفتاحك الخاص:
  GEMINI_API_KEY="AQ.Ab8RN6K2e8lcHV84aHUUgPeGt8rKQ0Bwx-b8D6BF1gN-fYHhaA"

خيار ب: للمستخدمين عبر الواجهة الرسومية مباشرة (سهل وسريع ومن المتصفح)
- توجه لصفحة "أدوات الاتصال" (Settings) من القائمة الجانبية للموقع.
- قم بتفعيل خيار "استخدام مفاتيح مخصصة خاصة بي".
- الصق رمز API الخاص بك من موقع Google AI Studio مباشرة في حقل Gemini Key.
- يتم حفظ هذا المفتاح محلياً وبأمان كامل في متصفحك داخل (localStorage) وسيتم تمريره للخادم لإجراء التوليد دون تخزينه خارجيًا.

------------------------------------------------------------------------
2. أين تضع مفتاح OpenRouter API Key؟ (الاحتياطي)
------------------------------------------------------------------------
أيضاً، يتوفر طريقتان لإعداد مفتاح OpenRouter:

خيار أ: عبر رموز البيئة السرية بالخادم
- أضف السطر التالي داخل ملف `.env` الذي قمت بإنشائه:
  OPENROUTER_API_KEY="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"

خيار ب: عبر الواجهة الرسومية مباشرة
- توجه لصفحة "أدوات الاتصال" في السايدبار.
- فعل خيار "استخدام مفاتيح مخصصة خاصة بي".
- الصق رمز OpenRouter في حقل OpenRouter Key المخصص ليتم تفعيله تلقائيًا.

------------------------------------------------------------------------
3. الملف المسؤول عن تكوين وإعداد معالجة الطلبات بالـ API
------------------------------------------------------------------------
الملف المسؤول عن استقبال ومعالجة الطلبات والتواصل مع مزودي الذكاء الاصطناعي هو:
  `/server.ts`

يقوم هذا الملف بـ:
1. جلب المفتاح المخصص الذي يرسله المستخدم من المتصفح (localStorage) إن وجد.
2. إذا لم يرسله المستخدم، فإن الخادم يبحث تلقائياً في رموز البيئة للتشغيل `process.env.GEMINI_API_KEY`.
3. يضمن هذا الأسلوب أماناً عالياً بحيث لا تظهر المفاتيح للمتصفح إلا بطلب العميل الملموس.

------------------------------------------------------------------------
4. المتغيرات والملفات التي يجب تعديلها يدوياً
------------------------------------------------------------------------
- لبيئة التطوير والإنتاج الخاصة بك، قم بإنشاء ملف `.env` وقم بإعداد المتغيرات التالية:
  GEMINI_API_KEY="AQ.Ab8RN6K2e8lcHV84aHUUgPeGt8rKQ0Bwx-b8D6BF1gN-fYHhaA"
  OPENROUTER_API_KEY="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"

------------------------------------------------------------------------
5. تحذير هام بخصوص الأمن والخصوصية (Security Warning)
------------------------------------------------------------------------
* تحذير أمني: إدخال أو تخزين مفاتيح API الخاصة بك في الواجهة الأمامية للمتصفح (كحفظها في localStorage) يعرضها للرؤية من خلال أدوات المطورين (DevTools) في حالة مشاركة الكمبيوتر أو في حالات الثغرات الأمنية (XSS).
* للإنتاج الفعلي والتشغيل التجاري الواسع: نوصي بشدة بوضع المفاتيح بملفات البيئة الخاصة بالخادم الخفي `.env` وتعطيل خيار إدخال المفاتيح من العميل لتكون مؤمنة ومحجوبة 100% عن أعين الزوار والواجهات الرسومية.

------------------------------------------------------------------------
6. خطوات تشغيل المشروع بالتفصيل
------------------------------------------------------------------------
لتشغيل المنصة ومراجعتها محلياً، اتبع الخطوات التالية بالترتيب:

الخطوة 1: تثبيت الحزم التابعة (Dependencies)
قم بفتح منفذ الأوامر بمجلد المشروع واكتب:
  npm install

الخطوة 2: تشغيل سيرفر المطورين (Vite + Express Proxy)
لتشغيل الخادم المحلي على المنفذ 3000 بذكاء:
  npm run dev

الخطوة 3: التصفح والمراجعة
افتح متصفحك وتوجه للرابط التالي:
  http://localhost:3000

------------------------------------------------------------------------
